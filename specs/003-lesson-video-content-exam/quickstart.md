# Quickstart: Lesson Video, Content & Exam

## Prerequisites

- Admin user with lesson permissions
- Published course with at least one enrolled student
- Optional: one published quiz on that course

## Admin path

1. Open `/admin/lessons/create` or course → Lessons tab.
2. Set title, course, status published.
3. Upload main video (or select existing) and mark as main.
4. Enter rich-text explanation in the content editor; save.
5. Attach the course quiz as lesson exam; save.
6. Upload optional PDF attachments.

## Student path

1. Log in as enrolled student → open the lesson.
2. Confirm main video is primary; rich text readable; PDFs listed separately.
3. Play video to end (or ≥90%); confirm exam CTA unlocks.
4. Start exam, submit attempt, see result.
5. Mark lesson complete if not auto-completed.

## Verify

- Reload lesson: video resume position preserved when possible.
- Before finishing video: exam start blocked with Arabic message.
- Lesson without quiz: no broken exam section.
- Lesson without video: exam unlocks after “تعليم كمكتمل”.
